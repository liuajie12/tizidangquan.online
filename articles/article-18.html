软路由与全屋透明代理搭建：OpenClash 与 ShellCrash 旁路由配置指南

📅 发布时间：2026年10月 ⏱️ 阅读时长：约 10 分钟 (2300 字) ✍️ 作者：梯子当权评测组

在传统的单机代理模式下，每个家庭成员的手机、笔记本电脑、平板电脑都必须单独下载安装 Clash 或小火箭客户端，每次上网都要手动开启代理，不仅繁琐耗电，而且很多智能设备根本无法安装代理软件：例如客厅的 Apple TV 4K、索尼智能电视、Nintendo Switch 游戏机、PS5 以及智能音箱。

如何才能实现“任何设备只要连上家里 Wi-Fi，无需任何客户端配置，就能自动、无感地访问全球网络，看 Netflix 4K、打外服游戏与调用 ChatGPT”？答案就是搭建「全屋透明代理（Transparent Proxy）」。

本文由梯子当权（tizidangquan.online）为你详细解析最稳健的“旁路由网络拓扑”，并手把手指导 OpenClash 与 ShellCrash 的核心配置实战。

一、核心网络拓扑：为什么强烈推荐“旁路由”而非主路由？

在家庭网络改造中，很多人一上来就想把硬路由换掉，直接用软路由拨号做“主路由”。但对于有家人的家庭网络而言，这种做法风险极高：一旦你在调试代理配置时写错了某行规则或内核死锁，全家人的宽带立刻彻底瘫痪，连微信、抖音都刷不出来，极易引发家庭矛盾。

🌟 旁路由（旁路网关）的绝对优势：

  • 原有网络架构不动：光猫与现有的华硕/小米 Wi-Fi 主路由器依然负责正常的 PPPoE 拨号与 DHCP 分发；
  • 软路由作为局域网普通设备接入：将一台小主机（如 N100、J4125、GL.iNet 或 NAS 虚拟机）插上网线连入主路由器，赋予一个固定的局域网 IP（例如 192.168.1.2）；
  • 按需指向，互不干扰：对于需要翻墙的 Apple TV、Switch 或自己的主力电脑，只需在设备网络设置中将「默认网关」与「DNS」手动改成 192.168.1.2。而家人的手机依然走主路由器 192.168.1.1，即使旁路由死机维护，家庭普通网络也 100% 毫无影响！

二、两大软路由核心插件对比：OpenClash vs ShellCrash

1. OpenClash（功能集大成者，Web 界面管理）

运行在 OpenWrt 固件上的图形化插件：

  • 优势：拥有极其完善的 LuCI Web 控制面板，策略组可视化拖拽，支持 Meta 内核、TUN 模式以及规则集自动更新；
  • 适用硬件：x86 软路由主机（如 Intel N100、N5105）、性能较好的 ARM 开发板（如树莓派 4B/5、友善 NanoPi R4S/R5S）。

2. ShellCrash（极简神兵，零开销全平台）

基于纯 Shell 脚本打造的轻量代理核心管理工具：

  • 优势：内存占用不到 20MB，不仅支持 OpenWrt，还能直接免刷机安装在小米路由器（AX3000/AX6000）、华硕梅林固件、GL.iNet 甚至威联通/群晖 NAS 的 Linux 终端中；
  • 管理方式：通过 SSH 输入 crash 呼出纯文本彩色菜单，或通过本地 Web 面板进行日常切换。

三、OpenClash 旁路由关键参数配置实战

搭建旁路由最常踩的坑是「DNS 回环风暴」与「国内流量异常绕行」。在 OpenWrt 的 OpenClash 设置中，务必牢记以下四大关键开关：

  1. 网络接口与物理连接设置： 进入 OpenWrt「网络」->「接口」->「LAN」修改：
    • IPv4 地址：设为主路由同一网段的固定 IP（如 192.168.1.2）；
    • IPv4 网关：填写主路由器 IP（192.168.1.1）；
    • IPv4 广播 / DNS 服务器：填写主路由器 IP 或公共 DNS（如 223.5.5.5）；
    • 重要：在页面最下方勾选 「忽略此接口（不在此接口提供 DHCP 服务）」，彻底关闭旁路由的 DHCP，防止与主路由抢占分配 IP！
  2. OpenClash 运行模式选择： 在「模式设置」中，强烈推荐勾选 「Fake-IP (TUN 模式)」。Fake-IP 模式不仅能把局域网所有设备的 DNS 解析开销压减到极限，还能完美捕获所有电视盒子和游戏主机的非标准协议数据流。
  3. 防火墙自定义规则（关键！）： 为防止主路由流量转发到旁路由时出现单边 NAT 丢包，进入 OpenWrt「网络」->「防火墙」->「自定义规则」，添加一行经典伪装指令： 
    iptables -t nat -I POSTROUTING -o br-lan -j MASQUERADE
  4. 策略组分流配置： 在策略组中，将 Apple TV 绑定的 Apple 服务和 Netflix 分别指定至港台或日本低延迟专线节点，保障家庭影院 4K HDR 杜比视界码率拉满。

四、选购适合软路由的机场套餐注意事项

软路由由于是“一台设备接入、代理全家几十台硬件”，在挑选机场时有两项核心要求：

  • 必须挑选“不限制同时连接设备数”的机场：有些机场严格限制“同时在线设备不超过 2 台”，软路由在向外并发上百条 TCP 连接时，极易被机场系统判定为多设备违规共享而自动熔断。本站推荐的 速界机场 与 边缘节点 均支持全套餐不限设备数连接，非常适合全屋软路由部署。
  • 套餐流量要足够充裕：全屋透明代理下，电视盒子常开 4K 视频、电脑后台自动同步 iCloud 与 Steam 更新，每月流量消耗通常在 300GB - 800GB 之间，建议搭配大流量月付套餐。
